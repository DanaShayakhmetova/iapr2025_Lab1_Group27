## Setup Instructions

To run the final_pipeline notebook, first download the **`data`** folder and make sure its structure looks like this:

- data
  - references
  - test
  - train
  - train_labels (contains YOLO bounding box txt files)


Then, run every code block except the **Training Classifier"** block, since training takes about an hour.  
The model weights are already provided in the folder, so you don’t need to retrain.
